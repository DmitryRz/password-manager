## Обзор проекта

Это веб-приложение для управления паролями. Оно позволяет пользователям хранить и организовывать свои учетные данные. Приложение состоит из клиентской части (SPA на чистом JavaScript) и серверной части (REST API на Spring Boot).

## Основной функционал

- **CRUD-операции для аккаунтов**: Создание, чтение, обновление и удаление учетных записей.
- **Просмотр списка аккаунтов**: Все сохраненные аккаунты отображаются в виде карточек.
- **Детальный просмотр**: Возможность открыть подробную информацию о каждом аккаунте.
- **Генератор паролей**: Встроенный инструмент для создания сложных и надежных паролей.
- **Поиск и фильтрация**: Возможность поиска аккаунтов по названию или имени пользователя, а также фильтрация по категориям.

## Технологический стек

### Бэкенд (Backend)

- **Язык**: Java 21
- **Фреймворк**: Spring Boot 3
- **API**: Spring Web (REST)
- **База данных**: Spring Data JPA
- **СУБД**: PostgreSQL
- **Сборка**: Maven

### Фронтенд (Frontend)

- **Язык**: JavaScript (ES6 Modules)
- **Архитектура**: MVP (Model-View-Presenter) с использованием самописного микро-фреймворка.
- **Разметка**: HTML5
- **Стилизация**: CSS3
- **Веб-сервер**: Nginx (для раздачи статических файлов)

### Контейнеризация

- **Docker**
- **Docker Compose**

## Запуск проекта

Для запуска проекта убедитесь, что у вас установлены **Docker** и **Docker Compose**.

1.  Склонируйте репозиторий на ваш компьютер.
2.  Перейдите в корневую директорию проекта.
3.  Выполните следующую команду в терминале:

    ```bash
    docker-compose up -d --build
    ```

4.  Эта команда соберет образы для клиента и сервера, запустит все необходимые контейнеры (базу данных, сервер, клиент) в фоновом режиме.

5.  После успешного запуска приложение будет доступно в вашем браузере по адресу:
    [http://localhost](http://localhost)
